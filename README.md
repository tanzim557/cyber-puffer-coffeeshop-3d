# Cyber Puffer 3D Coffee Shop

[![Three.js](https://img.shields.io/badge/Three.js-WebGL-black?style=for-the-badge&logo=three.js)](https://threejs.org/)
[![GSAP](https://img.shields.io/badge/GSAP-Animation-88CE02?style=for-the-badge&logo=greensock&logoColor=white)](https://greensock.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

A cutting-edge, futuristic 3D cyberpunk coffee shop interactive web experience. Merges WebGL 3D rendering with smooth momentum scrolling, dynamic model explosion views, custom particle cursors, and spatial audio.

---

## Key Features

- Interactive Model Explosion: Disassemble the 3D coffee machinery into component parts with animated tracking labels.
- Inertial Smooth Scroll: Fluid page scrolling engineered with Lenis smooth scroll library.
- Custom Particle Cursor: Reactive physics-driven cursor tracking with trail mechanics.
- Spatial Sound Design: Dynamic Web Audio soundscape and interactive click audio triggers.
- 3D HUD and Tracker Lines: Cyberpunk holographic billboards and dynamic tracker lines pointing to ingredients and machinery specs.

---

## Tech Stack

- 3D Graphics: Three.js (WebGL)
- Animation: GSAP (GreenSock Timeline and ScrollTrigger)
- Physics and Scroll: Lenis Smooth Scroll
- Audio: Web Audio API

---

## Getting Started

```bash
# Clone the repository
git clone https://github.com/tanzim557/cyber-puffer-coffeeshop-3d.git
cd cyber-puffer-coffeeshop-3d

# Install dependencies
npm install

# Start development server
npm run dev
```
